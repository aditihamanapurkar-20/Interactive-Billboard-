# UltraTech Interactive Billboard

Interactive Hindi experience: help **चूना लाल** build a strong house and learn why the right cement matters — built for UltraTech.

**Live site:** [https://aditihamanapurkar-20.github.io/Interactive-Billboard-/](https://aditihamanapurkar-20.github.io/Interactive-Billboard-/)

## Features

- Step-by-step house building (foundation → walls → cement → roof)
- Hindi dialogue with Indian Hindi text-to-speech (`hi-IN`)
- Soft, readable Devanagari typography
- UltraTech cement as the recommended choice
- Deployed automatically to GitHub Pages

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Deploy (GitHub Pages)

Pushes to `main` run the **Deploy to GitHub Pages** workflow.

**Repo owner must set once:**

1. GitHub → **Settings** → **Pages**
2. **Source** → **GitHub Actions**

Site URL:

`https://aditihamanapurkar-20.github.io/Interactive-Billboard-/`

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Lucide icons
